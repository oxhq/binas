# Fonted page text local oracle

Original Apache-2.0 sources and fixtures for the existing public `PdfRevisionRequest.page_text` operation. This work does not expand the P2b raw-text capability. Run from the isolated P3b repository with the already-installed bundled interpreter:

```powershell
$pdfOraclePython = 'C:\Users\garae\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe'
& $pdfOraclePython -B qa/fonted-text/oracle.py generate
& $pdfOraclePython -B qa/fonted-text/oracle.py verify SOURCE.pdf BINAS_OUTPUT.pdf Incremental REPORT.json
& $pdfOraclePython -B qa/fonted-text/oracle.py verify SOURCE.pdf BINAS_OUTPUT.pdf Compact REPORT.json
& $pdfOraclePython -B qa/fonted-text/oracle.py self-test SOURCE.pdf BINAS_OUTPUT.pdf Compact MUTANT_EVIDENCE_DIRECTORY
```

Generation defaults to `crates/binas-pdf/tests/fixtures/fonted-text`. The plain/Flate admitted sources are `fonted-text-plain.pdf` and `fonted-text-flate.pdf`. Their `-golden.pdf` counterparts are independently generated by replacing only the target stream payload; they do not call Binas. The manifest contains provenance, file hashes, object identities, and the operation contract. The generator and oracle reuse only fixture serialization, inventory, geometry, parser, and renderer helpers from the copied frozen P3a QA module. They do not mutate those helpers or call its P3a verifier. No download, installation, or dependency change occurs.

The exact operation replaces the first `ALPHA` occurrence on page zero with the longer `OMEGA-LONG`, with shared-content policy `Reject`. Page zero selects `/F1` at 14 points, origin `(40,150)`; `KEEP` remains on the next line. Its direct unique Contents reference is object 4. Target page zero and untouched page one share resource dictionary 7 and font dictionary 8. Font 8 is standard Type1 `/Helvetica` with `/WinAnsiEncoding` and explicit ToUnicode stream 27. The Type2 CMap injectively maps all 59 ASCII codes from 32 through 90 to their corresponding Unicode values, including hyphen. This pins the source character codes, selected font, encoding, and Unicode interpretation independently of Binas.

All three pages have valid selected fonts. Retained objects include independent page geometry/rotation, image data, metadata, Info, outlines, named destinations, attachment name tree and bytes, an AcroForm widget and appearance, and an unreferenced sentinel stream 28. IDs 1 through 28, generation zero, and `/Size 29` remain exact. The selected font and shared resources are preservation invariants. Only target stream 4's payload and `/Length` may change; the target's other dictionary entries, every non-target typed dictionary, and encoded/decoded non-target stream hashes must match the source. Sources must equal one of the generator's exact trusted fixture byte strings. Raw decoded target operations and operands and the entire decoded target byte string must equal the independently generated golden. These literal-token fixtures require the fixed literal replacement while preserving all other bytes; arbitrary trailing comments or whitespace drift are rejected. Source/output/expected target byte strings are retained for inspection.

The oracle uses installed pypdf 6.10.0 in strict mode to inventory every xref object, including the unreachable sentinel; compare IDs/generations, dictionaries, stream hashes, geometry, exact ContentStream operations, shared font/resource identities, explicit CMap bytes, Unicode extraction, and all non-layout trailer values including IDs/Info/Root/Size. Incremental must retain the exact source-byte prefix, exactly two revisions, and `/Prev` equal the source's startxref. Compact must have one revision and no `/Prev`.

The source and Compact reader phases must have no warnings. Installed pypdf emits `Xref table not zero-indexed. ID numbers for objects will be corrected.` on a legitimate Incremental subsection beginning at object 4. Incremental permits exactly that one candidate-intake diagnostic only after an independently generated nonzero-subsection control reproduces it and verifies every object ID/offset and the expected replacement operations. No non-strict downgrade is used. All messages are phase-labeled and retained; unexpected/later warnings and Python warnings fail closed. This is qualified diagnostic-bearing strict Incremental parsing, not warning-free or general conformance evidence. `pdfinfo` 26.07.0 must independently parse source, output, and golden with exit zero, empty stderr, and identical three-page geometry; commands and stdout/stderr are retained.

Poppler 26.07.0 renders all three pages at pinned 96 DPI, crop-box, antialiasing, FreeType, and thin-line settings directly to PNG. Each candidate target page must have exactly the independent golden's dimensions and decoded RGB pixels. Candidate pages one and two must exactly match source and golden. The expected source-to-golden change must exceed 50 changed RGB pixels and lie within the predeclared PDF region `[35,143,170,169]`, corresponding to pixel rectangle `[46,54,227,90]`. The independently generated fixture currently changes 1,080 pixels with bounding box `[53,66,181,81]`. The region and threshold were declared before observing Binas output. This verifies a visible intended target edit, without claiming source and replacement pixels should match.

The installed renderer emits exact missing `Symbol` and `ArialUnicode` display-font diagnostics during font initialization. An empty valid blank control must emit no diagnostics; independently valid Helvetica and Courier controls must emit the exact pinned two messages. All source/output/golden fonted renders must emit precisely the same pinned messages. No stderr is hidden; unexpected/extra diagnostics, nonzero exits, missing tools, or changed controls fail. The rendered evidence is explicitly a diagnostic-bearing local pixel comparison; it does not certify arbitrary font rendering, layout/reflow, OCR, standards conformance, or universal PDF compatibility.

Self-tests persist mutated PDFs and named comparison failures. A negative counts only when its intended check fails without an oracle exception. Controls cover wrong selected font, missing/wrong target, collateral target text, an added target-stream trailing comment, out-of-scope page text, shared resource/font change, ToUnicode CMap damage, image damage, and unreferenced sentinel damage. Separate render-only wrong-font and target-missing negatives prove the target pixel comparator itself detects those losses. The self-test mutants are synthetic local outputs, not Binas exports.

Planning-time refusal fixtures are `fonted-text-missing-cmap.pdf`, `fonted-text-missing-replacement.pdf` (hyphen missing from the reverse map), `fonted-text-ambiguous-cmap.pdf` (duplicate Unicode destination), and `fonted-text-shared-contents.pdf`. The parent public API tests characterize their exact refusal boundaries; this oracle does not infer those result codes. Optimized `-O` execution is rejected so required controls remain active. Python executable/version and pypdf/Pillow/Poppler versions are recorded in reports.
